## Структура заняття:

- Працюємо з фоном Hero
- Створюємо `svg-sprite`
- Додаємо декоративні елементи: Header, Benefits та Made
- Працюємо з іконками
- Додаємо оверлей з текстом для карток секції Bestsellers

## Технічне завдання:

- Для всіх іконок використовується векторна графіка у форматі `svg`
- Всі іконки з SVG-спрайту додані в HTML за допомогою тегів `<svg>` і `<use>`
- Для іконок в html явно вказано width і height
- При ховері або фокусі іконки повинні переходити в активний стан - змінювати
  колір, якщо це зазначено в макеті
- Велике зображення з ефектом затемнення (під хедером) виконано як фон. Для
  затемнення використовується багатошаровий фон з градієнтом
- В головній навігації, за допомогою псевдоелемента `::after`, зроблено
  підкреслення посилання
- Оверлей з текстом на картках секції Bestsellers з'являється при ховері в
  будь-якому місці картки
