## Структура заняття:

- Організація базових стилів для позиціювання та стилізація Header
- Стилізація Hero та Benefits
- Стилізація Ingredients та Made
- Стилізація Products та Bestsellers
- Стилізація Reviews та Footer

## Технічне завдання:

- Допускається глобальне скидання стилів за селектором тегу для
  елементів `<h1>...<h6>, <p>, <ul> <ol>`
- Створений загальний допоміжний клас `.container` для центрування і обмеження
  контенту по ширині
- `.container` обгортає контент `<header>, <footer>` і `<section>`, тобто
  знаходиться всередині них
- Для розташування елементів використовується `flexbox-layout`, але тільки там,
  де це необхідно.
- Фінальні розміри блоків в браузері відповідають макету
- У елементів відсутня фіксована висота, вона визначається їх контентом
- Для всіх секцій використовується один клас `.section`
- Для правильного приховування заголовка секції в файлі в `common.css`
  використовується клас `.sr-only`
